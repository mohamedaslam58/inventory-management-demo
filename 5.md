This behavior happens in Angular for two common reasons:

Incorrect Navigation Syntax or Path Name: this.router.navigate expects an array of route segments (e.g., ['/masters/customer']), not just a string like 'customer-master'. If the route path isn't an exact match in app.routes.ts, Angular updates the browser URL bar but fails to match or render any component.

Missing <router-outlet></router-outlet>: If the layout or main shell component doesn't include <router-outlet></router-outlet>, Angular has nowhere to render the routed view component.

Here is how to fix it step-by-step:

Step 1: Update Navigation Call in login.component.ts
Ensure you are passing an array of path segments with a leading slash to navigate(), matching the exact path structure defined in app.routes.ts:

TypeScript
// ❌ Incorrect
// this.router.navigate('customer-master');

// ✅ Correct (Array format matching app.routes.ts path)
this.router.navigate(['/masters/customer']);
Step 2: Ensure <router-outlet> and DevExtreme/Common Modules in app.component.ts
Make sure your root AppComponent template includes <router-outlet></router-outlet> and imports RouterOutlet in its @Component decorator:

TypeScript
import { Component } from '@angular/core';
import { RouterOutlet } from '@angular/router';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [RouterOutlet], // 👈 Must be imported for standalone components
  template: `
    <main>
      <router-outlet></router-outlet>
    </main>
  `
})
export class AppComponent {}
Step 3: Check Component Export Signature in customer-master.component.ts
Because we used dynamic import() for lazy loading in app.routes.ts:

TypeScript
loadComponent: () => import('./features/masters/customer-master/customer-master.component').then(m => m.CustomerMasterComponent)
Verify that CustomerMasterComponent is exported as a named export in customer-master.component.ts:

TypeScript
import { Component } from '@angular/core';
import { DxDataGridModule } from 'devextreme-angular';

@Component({
  selector: 'app-customer-master',
  standalone: true,
  imports: [DxDataGridModule],
  templateUrl: './customer-master.component.html'
})
export class CustomerMasterComponent { // 👈 Ensure class name matches m.CustomerMasterComponent exactly
  // component logic
}
